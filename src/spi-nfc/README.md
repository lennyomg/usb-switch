This sample uses a PN532 NFC reader over SPI to select a USB port with a tag UID. Connect MOSI to PA1, MISO to PA2, SCK to PA3, and CS to PA4. To learn a tag, first select a port with the built-in button. Then hold the button and present the tag to the reader. The LED blinks three times when you release the button after learning. The selected port is saved to EEPROM and restored on startup.
